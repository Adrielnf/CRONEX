# CRONEX

## Sistema Inteligente para Gestão da Produção Terceirizada

O CRONEX é um sistema web desenvolvido para auxiliar empresas do setor de confecção no gerenciamento da produção terceirizada.

A plataforma centraliza informações sobre produtos, terceirizadas, produções, prazos e coletas, permitindo maior controle e previsibilidade durante o processo produtivo.

## 🎯 Objetivo

Centralizar a gestão da produção terceirizada em uma única plataforma, permitindo acompanhar o andamento das produções, registrar prazos, acompanhar liberações de peças e organizar a logística de coleta.

## 🚀 Principais funcionalidades

- Cadastro de produtos
- Cadastro de empresas terceirizadas
- Cadastro e acompanhamento de produções
- Controle de prazos
- Confirmação de prazo pelas terceirizadas
- Registro de problemas e possíveis atrasos
- Liberação parcial de peças
- Gestão de coletas
- Acesso específico para coletor
- Integração com Google Maps para localização das terceirizadas
- Dashboard gerencial
- Previsão e acompanhamento de coletas
- Relatórios de produção e desempenho

## 👥 Perfis do sistema

### Administrador
Responsável pelo gerenciamento dos produtos, terceirizadas e produções, além do acompanhamento geral da operação.

### Terceirizada
Responsável por acompanhar as produções recebidas, confirmar prazos, informar problemas ou atrasos e registrar peças disponíveis para coleta.

### Coletor
Responsável por visualizar as coletas disponíveis, consultar os dados da terceirizada, acessar sua localização e registrar as peças coletadas.
